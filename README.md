# Rotinas ADVPL para Soluções Corporativas

Este repositório reúne fontes ADVPL e TL++ criados por **Luiz Moura** para
soluções corporativas no ecossistema TOTVS Protheus. As rotinas atendem a
necessidades de negócio, automação de processos, integrações e apoio à tomada
de decisão.

## Organização

Os arquivos foram agrupados de acordo com a finalidade predominante de cada
rotina. Os subcaminhos de origem são preservados dentro das categorias para
facilitar a localização de arquivos relacionados.

| Pasta | Conteúdo |
| --- | --- |
| `integracoes/` | APIs, web services, troca de XML, documentos fiscais e comunicação com serviços externos. |
| `atualizacoes/` | Pontos de entrada, regras de negócio, validações, gravações e automações de processos do Protheus. |
| `relatorios/` | Relatórios, exportações para Excel e rotinas de análise operacional ou gerencial. |
| `consultas/` | Consultas SQL, filtros, pesquisas e navegações para apoio à operação. |

## Tecnologias

- **ADVPL** e **TL++**
- TOTVS Protheus e seus pontos de entrada
- Integrações HTTP, APIs e serviços fiscais
- SQL, geração de relatórios e exportação de dados

## Observações importantes

- A classificação representa o objetivo principal identificado para cada
  rotina; algumas podem atender mais de uma categoria.
- Estes fontes foram desenvolvidos para contextos corporativos específicos e
  devem ser revisados, parametrizados e homologados antes do uso em outro
  ambiente.
- Credenciais, URLs privadas, dados de produção e arquivos de configuração de
  ambiente não devem ser adicionados ao repositório.
